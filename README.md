# GoBuy Product Trust — Claude Plugin

Marketplace-evidence trust scores for AI agents: a 0-100 Evidence Score with signal breakdown for Amazon, Walmart, Target, and Best Buy listings.

This plugin bundles the GoBuy remote MCP server (`https://mcp.gobuy.ai/mcp` — no API key required) and a `/gobuy` skill for trust-checking marketplace products.

- **Homepage:** https://gobuy.ai
- **For agents:** https://gobuy.ai/for-agents
- **Visual audit tool:** https://audit.gobuy.ai
